# Instalação e Execução do ESM Forum

Este documento apresenta os passos necessários para instalar e executar o ESM Forum, composto por um backend em Node.js/Express com banco de dados SQLite e um frontend em React.

## Pré-requisitos

Para executar o projeto, é necessário ter instalado:

- Node.js
- npm
- Navegador web
- Editor de código, como o VSC

Durante a configuração deste projeto foi utilizada a versão **20.19.6 do Node.js** e a versão **10.8.2 do npm**.
