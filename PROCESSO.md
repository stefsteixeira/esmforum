# Processo Ágil

## Metodologia escolhida: Kanban

Para o planejamento e acompanhamento das melhorias do ESM Forum, foi escolhido o Kanban.

A escolha foi feita por se tratar de um projeto com um conjunto de funcionalidades já definido, permitindo acompanhar de forma simples e visual o andamento de cada tarefa. Com o Kanban, as funcionalidades podem avançar pelo fluxo de desenvolvimento conforme forem sendo trabalhadas, sem a necessidade de organizar o trabalho em sprints.

O quadro será organizado nas seguintes etapas:

- A Fazer
- Em Andamento
- Em Revisão
- Concluído

Cada uma das cinco funcionalidades solicitadas será representada por um card no GitHub Projects. Dessa forma, será possível visualizar quais funcionalidades ainda precisam ser desenvolvidas, quais estão em desenvolvimento, quais estão sendo revisadas e quais já foram concluídas.

Também será definida uma ordem de prioridade para as funcionalidades, considerando a utilidade para os usuários e a organização do desenvolvimento.

Essa abordagem facilita o acompanhamento contínuo do projeto e permite que novas tarefas ou ajustes sejam incorporados ao fluxo quando necessário.
