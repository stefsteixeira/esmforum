# Histórias de Usuário

Este documento apresenta as histórias de usuário definidas para a evolução do ESM Forum. Foram selecionadas três funcionalidades entre as propostas para o sistema, considerando as necessidades dos usuários e a utilidade de cada recurso para a plataforma.

As funcionalidades selecionadas foram:

1. Sistema de votação nas perguntas (upvote/downvote);
2. Busca de perguntas por palavra-chave;
3. Notificações de novas respostas às próprias perguntas.

## História 1 – Sistema de votação nas perguntas

### História de usuário

Como usuário do ESM Forum, quero poder votar positiva ou negativamente nas perguntas para indicar quais considero mais relevantes ou úteis para a comunidade.

### Critérios de aceitação

- O usuário deve conseguir dar um voto positivo em uma pergunta;
- O usuário deve conseguir dar um voto negativo em uma pergunta;
- O sistema deve exibir a quantidade de votos da pergunta;
- O voto deve ser registrado e refletido na pontuação apresentada pelo sistema.

### Prioridade

**Alta (P0).**

### Justificativa

A funcionalidade de votação permite que os próprios usuários indiquem a relevância das perguntas publicadas. Por ser uma forma direta de interação com o conteúdo e ajudar a destacar perguntas consideradas importantes pela comunidade, foi definida como uma funcionalidade de alta prioridade.

## História 2 – Busca de perguntas por palavra-chave

### História de usuário

Como usuário do ESM Forum, quero pesquisar perguntas utilizando palavras-chave para encontrar conteúdos relacionados ao assunto que estou procurando.

### Critérios de aceitação

- O sistema deve disponibilizar um campo para pesquisa de perguntas;
- O usuário deve conseguir informar uma palavra ou termo de busca;
- O sistema deve exibir as perguntas que contenham o termo pesquisado;
- Caso nenhuma pergunta seja encontrada, o sistema deve informar que não existem resultados para a busca realizada.

### Prioridade

**Alta (P0).**

### Justificativa

A busca facilita a localização de informações já publicadas no fórum e evita que o usuário precise percorrer manualmente todas as perguntas cadastradas. Por melhorar diretamente a navegação e o acesso ao conteúdo, essa funcionalidade foi definida como de alta prioridade.

## História 3 – Notificações de novas respostas

### História de usuário

Como usuário do ESM Forum, quero receber uma notificação quando uma nova resposta for publicada em uma pergunta criada por mim, para que eu possa acompanhar as interações relacionadas às minhas perguntas.

### Critérios de aceitação

- O sistema deve identificar quando uma nova resposta for adicionada a uma pergunta;
- O autor da pergunta deve receber uma notificação sobre a nova resposta;
- A notificação deve permitir identificar a pergunta que recebeu a resposta;
- O usuário deve conseguir visualizar suas notificações no sistema.

### Prioridade

**Média (P1).**

### Justificativa

As notificações facilitam o acompanhamento das perguntas publicadas pelo usuário e incentivam sua participação nas discussões. Entretanto, o funcionamento básico do fórum não depende desse recurso, por isso ele foi classificado com prioridade média.
